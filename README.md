## Deskripsi
Aplikasi console berbasis Java untuk sistem manajemen bioskop mini. Memodelkan Film, Studio, Tiket, dan Bioskop sebagai class, dengan antrean tiket sebagai ADT Queue buatan sendiri. Data disimpan di memori selama program berjalan.

## Cara Menjalankan
1. Buka proyek di IntelliJ IDEA.
2. Jalankan class MenuBioskop (src/bioskop/MenuBioskop.java).
3. Pilih menu dengan mengetik angka lalu Enter.

## Struktur Folder
- src/bioskop : source code Java
- docs : class diagram, catatan rancangan, dan tabel hasil pengujian
- pengujian : screenshot hasil pengujian
